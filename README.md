# DevTools Hub ⚡

> Tất cả công cụ developer cần, trong một trang duy nhất.

## 🔥 Features

- 🔒 **100% Offline** - Mọi thứ chạy trên trình duyệt, không gửi data lên server
- ⚡ **Siêu nhanh** - Không cần tải, không cần cài đặt
- 🆓 **Miễn phí hoàn toàn** - Không quảng cáo, không giới hạn
- 🛡️ **Bảo mật tuyệt đối** - Không thu thập data, không tracking

## 🛠️ Công cụ có sẵn

| Công cụ | Mô tả |
|---------|-------|
| 📋 JSON Formatter | Format, validate & minify JSON |
| 🔐 Base64 Encode/Decode | Mã hóa và giải mã Base64 |
| 🔗 URL Encode/Decode | Encode và decode URL components |
| 🔑 Hash Generator | Tạo MD5, SHA-1, SHA-256, SHA-512 |
| 🧪 Regex Tester | Test regex với highlighting real-time |
| 🎨 Color Picker | Chọn màu và chuyển đổi HEX, RGB, HSL |
| 📝 Lorem Ipsum | Tạo text Lorem Ipsum |
| ⏰ Timestamp Converter | Chuyển đổi Unix timestamp |
| 🎫 JWT Decoder | Giải mã JWT token |
| 🔍 Diff Checker | So sánh 2 đoạn text |
| 📖 Markdown Preview | Xem trước Markdown real-time |
| 🆔 UUID Generator | Tạo UUID v4 ngẫu nhiên |
| 🔢 Text Counter | Đếm ký tự, từ, câu |
| 📐 CSS Unit Converter | Chuyển đổi đơn vị CSS |
| 🔢 Number Base Converter | Chuyển đổi hệ số |

## 🚀 Deploy

### Vercel
1. Push code lên GitHub
2. Import repo vào [Vercel](https://vercel.com)
3. Deploy! (Không cần config gì thêm)

### GitHub Pages
1. Settings → Pages → Source: main branch
2. Done!

## 💻 Phát triển

Chỉ cần mở `index.html` trên trình duyệt. Không cần build tool hay package manager.

```bash
# Clone repo
git clone https://github.com/YOUR_USERNAME/DevTools-Hub.git
cd DevTools-Hub

# Mở trên trình duyệt
start index.html
```
