## 😤 The Problem

You have 20+ browser tabs pinned to random tool sites. Half of them are ugly.
A third have ads screaming at you. And at least one of them is quietly
**shipping your API keys and JSON payloads to a server you've never heard of.**

## ✅ The Fix

<table>
<tr>
<td width="50%" valign="top">

**🔒 Private by architecture**
Nothing you paste ever leaves your browser. Not analytics, not "for debugging," not ever.

**⚡ Instant, always**
No spinners. No cold starts. No network round-trip between you and your data.

</td>
<td width="50%" valign="top">

**🎨 Actually pretty**
Linear/Vercel-inspired UI. Dark & light themes that don't look like an afterthought.

**📦 Zero dependencies**
Pure HTML/CSS/JS. No React, no build step, no `node_modules` black hole.

</td>
</tr>
</table>

## ⌨️ Navigation

No sidebar. No clutter. Just a command palette.

| Key | Action |
|:--|:--|
| `Ctrl` `K` | Open / close the command palette |
| `↑` `↓` | Move between tools |
| `Enter` | Launch the focused tool |
| `Esc` | Close palette / back to home |
| *(type anything)* | Fuzzy‑search every tool at once |

We welcome contributions of all kinds! Whether you want to add tool #51, fix an edge-case bug, or polish UI/UX:
